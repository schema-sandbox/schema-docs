# Schema Docs v0.1.4 Release Notes

v0.1.4 preserves v0.1.3 and:

- Failed or unavailable optional PDF extractors use built-in extraction as a late fallback only when no usable existing result would be replaced.
- Empty, title-only, or different-extractor fallback retries cannot overwrite existing PDF Markdown; the UI reports the failed retry and keeps the active editor unchanged.
- Legacy empty or no-text-layer PDF caches are rejected and rebuilt instead of being reused.
- Builds disable Python bytecode, clean stale runtime files, and reject `__pycache__`, `*.pyc`, and `*.pyo`.
- Packaging verifies Node, Tauri, and Cargo versions; successful explicit extractor selection is unchanged.

The new Setup, MSI, portable ZIP, and hashes remain public-preview candidates until F-012 visible desktop verification is complete; v0.1.3 stays available.
