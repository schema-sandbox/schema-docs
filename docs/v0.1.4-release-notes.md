# Schema Docs v0.1.4 Release Notes

v0.1.4 preserves v0.1.3 and:

- Failed or unavailable optional PDF extractors use built-in extraction as a late fallback only when no usable existing result would be replaced.
- Empty, title-only, or different-extractor fallback retries cannot overwrite existing PDF Markdown; the UI reports the failed retry and keeps the active editor unchanged.
- Legacy empty or no-text-layer PDF caches are rejected and rebuilt instead of being reused.
- Desktop `Open Markdown` uses Tauri directly without importing a workspace copy.
- Excel and CSV imports now open a dedicated visible spreadsheet preview with real cell values, up to 20 preview rows, and switchable worksheet tabs. The preview is replaced or cleared when the active dataset, document, Markdown file, or workspace changes.
- XLSX worksheet relationships accept root-relative `/xl/worksheets/...` targets, preserving every worksheet and its name.
- PPTX and PDF preview images are loaded through the token-protected, workspace-confined `/api/workspace-asset` route. Unicode paths are supported, while remote images, traversal, and unsupported file types remain blocked.
- Packaged runtime bootstrap uses a unique session directory for each launch. The WebView accepts only a loopback marker bound to the managed child process PID and session nonce, rejects stale log markers and mismatched API origins, and uses bounded request retries and timeouts.
- Desktop exports use a native Tauri save dialog owned by the main window. Cancelling no longer reports success; extensions are normalized and validated; each approved external destination is authorized for one finalization only.
- Full HTML export for segmented PDFs now renders server-side, reconstructs cross-segment Markdown blocks such as tables, lists, paragraphs, code, and formulas, writes every segment into one self-contained HTML file, and streams local images into the output instead of assembling image payloads in the browser.
- Legacy PDF formula-image lines that previously parsed as indented code are normalized during reading and HTML export, so existing workspaces preserve every generated formula image without re-importing the PDF.
- Manifest refresh keeps the primary record list available when optional capability or source-change checks fail, and it refreshes an active spreadsheet from the latest manifest object.
- Builds disable Python bytecode, clean stale runtime files, and reject `__pycache__`, `*.pyc`, and `*.pyo`.
- Packaging verifies Node, Tauri, and Cargo versions; successful explicit extractor selection is unchanged.
- Desktop diagnostics and the first-workflow check are available under the collapsed developer Sample and test tools section.

The rebuilt Setup, MSI, and portable ZIP passed the public-preview gate on 2026-09-15 after strict F-012 verification of the matching artifact. Native desktop checks covered XLSX worksheet switching, PPTX/PDF image loading, save-dialog cancellation, and complete six-part HTML export. Evidence is recorded in `output/desktop-unblock-v0.1.4/desktop-verification-record.filled.json`. This verification used the developer Windows machine; clean-machine installer certification remains separate. Earlier v0.1.0-v0.1.3 packages remain available, and the previous v0.1.4 packages are backed up in `output/desktop-unblock-v0.1.4/previous-v0.1.4/`.
