# Schema Docs v0.1.3 发行说明

发布日期：2026-07-28

v0.1.3 是基于真实超大文件完整复测形成的稳定性修订版。它保留 v0.1.2 的安全边界，并修复发布后出现的文档选择、外部 Markdown 打开/保存、公式布局识别、超大数学文档 PDF 导出超时等回归。

## 相对 v0.1.2 的主要改进

| 领域 | v0.1.2 | v0.1.3 |
|---|---|---|
| 自动化回归 | 332 通过、1 跳过 | 380 通过、1 跳过、0 失败 |
| PDF 公式布局 | 分数可能被误判为上下标；两项公式辅助函数缺失 | 补充分数语义判断、视觉回退和行内算子基线重连 |
| PDF 数学字体 | 部分 CMSY CID 映射残留 | 增加尖括号、单竖线和双竖线映射 |
| 超大 PDF 导出 | 固定 180 秒浏览器超时可能中断复杂数学教材 | 按 HTML 体积和图片数量自适应延长超时 |
| 外部 Markdown | 安全加固后，桌面“打开”路径可能无法继续原位读取/保存 | 增加经原生文件选择器授权的受限读写桥；只允许已授权 Markdown |
| 文档选择状态 | 导入后当前记录与列表选择可能不同步 | 统一当前记录、选中记录和 Markdown 工作台刷新 |
| 分段提示 | 切换到非分段文档后可能残留旧提示 | 切换记录时清除过期分段状态 |
| Markdown 保真导出 | 外部手写 Markdown 的首尾空白可能被规范化 | `.md` 导出保持源文档外层空白，复测样本 SHA-256 完全一致 |
| 大请求处理 | 令牌保护 JSON 请求体上限 8 MiB | 提升至 64 MiB；文件上传上限仍保持 256 MiB |
| 发布门禁 | 旧规模预算与版本目标 | 同步 v0.1.3 版本、1.3 MB 运行时预算和 43,000 行总量预算 |

- 4 工作表 XLSX：工作表、希腊字母列名和 SQL 查询通过。
- 公式 Markdown：20 个渲染表达式，导出 Markdown 与源文件 SHA-256 一致。
- 高中物理竞赛 DOCX：161,176 字符、2 段、363 个媒体资源，分段及合并导出通过。

完整证据见 `docs/客户视角全面测试报告_2026-07-28_v0.1.3.md`。

## 已知限制

- `math-deep.pdf` 的特殊字体子集仍有 CID/PUA 残留，复杂公式必须进行质量复核；本版不宣称数学 OCR 完全重建。
- 高中物理竞赛 DOCX 中 723 个旧 DrawingML/VML 对象没有图片关系，当前以明确占位说明保留，不伪造图像。
- Marker 可选通道在本测试环境未安装，因此没有纳入本版通过声明。
- 安装包尚未进行商业代码签名；Windows 可能显示未知发布者提示。
- `release-readiness` 仍要求在目标 Windows 机器上由人工完成 F-012 可见桌面验证，包括原生文件选择器证据；在完成该签字前，本批产物应视为可安装的 v0.1.3 发布候选，而不是已获人工签字的公共标签。
